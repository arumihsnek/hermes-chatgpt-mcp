# hermes-chatgpt-mcp

Read-only MCP integration between ChatGPT and the canonical Hermes query surface.

The project scaffold is intentionally minimal until Hermes reconnaissance establishes the runtime, adapter boundary, and deployment contract. Version 0.1 will expose query tools only; it will not create, update, dispatch, or otherwise mutate Hermes state.

See `docs/architecture/` for the integration decisions and `tests/` for verification.
